# TWIN Standards W3C DCAT

Models which define the structure of [W3C Data Catalog Vocabulary (DCAT)](https://www.w3.org/TR/vocab-dcat-3/) Version 3.

## Installation

```shell
npm install @twin.org/standards-w3c-dcat
```
